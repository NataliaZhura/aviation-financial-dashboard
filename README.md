# Финансовый дашборд АО «ЮТЭЙР-Вертолетные услуги»

Версия: 17 сентября 2026 года.

## Ссылка на дашборд

Опубликованная версия дашборда:

[Открыть финансовый дашборд](https://script.google.com/macros/s/AKfycbzh3nq0a3aS8yrmkfJiSCzV_ClNfqs7e6TeEDwYvC3sHYoQvDvR37Pu-S5Xq4xS-Q/exec?page=dashboard)

Ссылка ведет на опубликованное развертывание Apps Script. Для доступа внешних пользователей в настройках развертывания должен быть выбран вариант «все».

## Состав

- `apps-script/` - файлы Google Apps Script для многостраничного дашборда.
- `data/Плоская_таблица_для_полного_импорта_с_финмоделью.csv` - единый источник данных для листа `Плоская_таблица` в Google Таблицах.

## Порядок запуска

1. В Google Таблицах импортируйте CSV с заменой листа `Плоская_таблица`.
2. В редакторе Apps Script замените одноименные файлы содержимым из папки `apps-script`.
3. Сохраните проект и откройте Web App по адресу `/dev?page=dashboard`.

## Методика

- денежные значения в исходном CSV хранятся в тыс. руб.; дашборд показывает их в млн руб.;
- амортизация для расчета EBITDA компании: 3% от основных средств за год;
- EBITDA компании: EBIT + расчетная амортизация;
- историческая отчетность компании и прогноз новой сделки Ми-8МТВ-1 показаны отдельно;
- DSCR новой сделки в финансовой модели: EBITDA проекта / годовой лизинговый платеж;
- FCF проекта не подменяет DSCR и выводится отдельным показателем.

## Ограничения

Прогноз сделки Ми-8МТВ-1 с 2026 года является модельным расчетом. Он не является фактической отчетностью компании и не должен заменять подтвержденные балансовые показатели, ОДДС или юридические условия лизинга.

Исходный Excel-файл финансовой модели намеренно не включен в репозиторий. В CSV сохранены ссылки на листы и ячейки источника для аудита расчета.
